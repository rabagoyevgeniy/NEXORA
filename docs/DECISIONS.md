# NEXORA — Журнал решений

Формат: дата — решение — обоснование. Решения не пересматриваются без записи о пересмотре.

## 2026-08-12

**D-001. Жанр: текстовая PvP-дуэль на LLM-движке («Грамматика»).**
Обоснование: единственный жанр, структурно недоступный большим студиям И совместимый с workflow «промпты с телефона в Cursor».

**D-002. LLM — переводчик, не судья.**
LLM: фраза → структура. Исход считает детерминированный код. Причина: защита от prompt injection + гарантия честности.

**D-003. Ходы одновременные, вскрытие как в покере.**
Причина: снимает латентность LLM, снимает реалтайм-нетворкинг, добавляет чтение противника.

**D-004. Прекаст обязателен.**
Черновик разбора до отправки. Причина: убивает главный риск — непредсказуемость собственных действий.

**D-005. Эрозия заклинаний.**
Частота использования фразы в мире ↑ → цена ↑. Первооткрыватель — перманентная скидка. Причина: анти-мета, встроенная в экономику.

**D-006. Лимит фразы — 12 слов.**
Причина: поэзия, а не эссе; защита от «кто напишет длиннее»; контроль стоимости инференса.

**D-007. Web-only, Vercel, React+TS+Supabase+Anthropic API.**
Причина: разработка и проверка с телефона; переиспользование паттернов Null Club / CoachFlow.

**D-008. Документация концепта живёт в этом репо, коммитит только Cursor.**
Причина: правило «один агент на репозиторий» (урок Aqua Trench). Ideation — в чате Claude, файлы переносятся промптом.

**D-009. Первая проверка фана — дуэль против ИИ-противника, не hot-seat.**
Причина: тестируется в одиночку, из любого места.

## 2026-08-13 (итерация 3 — экономика)

**D-010. Деньги покупают пространство для творчества, не силу.**
Стержневой принцип монетизации. Мана не продаётся никогда.

**D-011. Чернила — мета-ресурс на новые заклинания.**
Новая фраза = платный инференс = Чернила. Известная = кэш = бесплатно. Игровой ресурс зеркалит себестоимость. Дневной бесплатный запас = потолок расходов разработчика на игрока.

**D-012. Рейтинг изолирован от денег.**
Бюджет новизны в рейтинговом матче одинаков для всех (3 новых заклинания/дуэль), Чернила в рейтинге не действуют. Платное преимущество = только знание из Лаборатории («шахматный учебник», не «лишний ферзь»).

**D-013. Роялти чернилами за адопцию.**
Использование твоего заклинания другими начисляет тебе Чернила. Творческое ядро выходит на самоокупаемость by design.

**D-014. Открытие регистрируется только в матче против человека.**
Лаборатория не открывает заклинания. Защита от бот-фарма открытий + кластеризация эмбеддингов против сквоттинга вариаций.

**D-015. Модель дохода: подписка + разовая косметика + сезонные тома.**
Подписка «Кодекс» ~$6/мес. Конкретные числа — после данных прототипа (Q-08).

## 2026-08-13 (итерации 4–7 — мета-слой)

**D-016. ПЕРЕСМОТР D-005: роялти-скидка первооткрывателя → Сигнатуры.**
Найдено противоречие D-005 × D-012: перманентная скидка = вертикальная прогрессия, протащенная в честный рейтинг (старые аккаунты > лучшие формулировщики). Замена: автор «подписывает» открытие → иммунитет к эрозии (базовая цена навсегда), лимит слотов печатей 3→7–9, рост слотов только игрой. Роялти чернилами (D-013) сохраняется без изменений.

**D-017. Прогрессия — в ширину, не в высоту.**
Никакого роста цифр урона/HP. Рост = слоты сигнатур, школы, модификаторы, знание. Заработанная ширина легитимна, купленная — нет.

**D-018. Открытия контекстуальны: заклинание × среда.**
Новая арена = новая целина открытий. Среды обязательны; сезонная арена = возобновляемый источник «золотой лихорадки» для поздних игроков. Направление Q-02 предрешено.

**D-019. Выцветание печатей.**
Заклинание без использования сезон → активная печать спадает, доступно переоткрытие. Летопись первого автора вечна (слой истории), печать циклична (слой власти). Аналог: рекорд Болта вечен, чемпион мира — сегодняшний.

**D-020. Q-03 ЗАКРЫТ: асинхрон — базовый режим.**
Асинхронные дуэли (одновременные ходы, резолв по готовности обоих) = ядро мобильного retention + решение матчмейкинга малой базы. Синхронная дуэль = тот же движок в быстром темпе, не отдельный режим.

**D-021. MVP retention-слой = асинхрон + дневные Чернила. Точка.**
Контракты v1.1, турниры v1.2, сезоны при живой базе. Анти-scope-creep для соло-разработки.

**D-022. Эволюция без патчей.**
Эрозия двигает мету сама; сезонные арены = твики тегов среды; мировые события = твики коэффициентов детерминированного слоя.

## 2026-08-13 (итерации 8–10 — запуск и психология)

**D-023. Эпоха Безмолвия + Открытие Гримуара как событие запуска.**
Предсезон: игра играбельна, Гримуар запечатан. Решает холодный старт (Q-09) без ослабления D-014; даёт окно ред-тиминга (Q-04) и калибровку эрозии (Q-05). Дата Открытия — по метрике живой базы.

**D-024. Открытия — только в matchmade-дуэлях.**
Вызовы друзей играбельны, но не регистрируют открытия (анти-сговор). ИИ-матчи не регистрируют никогда. UI обязан явно маркировать нерегистрирующие дуэли.

**D-025. Судья нем в вопросах качества.**
Язык системы — только физика. Мана = масштаб, не оценка. Системная похвала запрещена в обе стороны; признание — только от людей.

**D-026. Экран поражения начинается с добычи.**
Увиденные заклинания → записная книжка с разбором. Проигрыш = разведка. Побочная петля: распространение заклинаний победителя через проигравших → роялти (D-013).

**D-027. Культ КПД.**
Эффект/мана — подсвечиваемая метрика мастерства. Косметическая слава, без наград силой.

**D-028. Никаких скрытых поддавков.**
Матчмейкинг по открытому рейтингу — единственный регулятор сложности. Pity-механики запрещены.

**D-029. Арена как муза.**
Свойства среды видимы как слова-аффордансы: источник идей против чистого листа + декларация физики арены. Подсказки готовыми фразами запрещены.

## 2026-08-13 (итерации 11–13 — онбординг и воронка)

**D-030. Time-to-magic < 60 сек.**
Холодный старт в сцену без регистрации/меню/синематиков. Гостевой аккаунт молча; имя — после первой дуэли (идентичность после инвестиции).

**D-031. Мир всегда отвечает.**
Состояния «invalid input» не существует: любой ввод резолвится минимум в шёпот (0 эффекта, 0 маны, 0 стоимости). Оба тира ввода видны с нулевой секунды; порядок (свободный vs осколки) — A/B прототипа.

**D-032. Инициация — открытый наставник.**
Дух объявляет себя учителем; условие завершения — первое эффективное заклинание игрока; поражения нет. Скрытых поддавков нет по построению (согласовано с D-028). Контент духа: ~20 скриптованных битов + LLM в жёсткой персоне.

**D-033. УТОЧНЕНИЕ D-023: расслоение кэша и летописи.**
Инфраструктурный кэш фраз работает с первого дня (независим от Безмолвия). Безмолвие запечатывает только летопись (имена/печати/роялти). Закрыта дыра: предсезон был бы периодом максимальной себестоимости инференса.

**D-034. Реплей-страница = воронка.**
Каждый шаренный реплей заканчивается полем «Скажи своё слово» → бесшовный вход в Инициацию. Требуется rate-limit по IP (→ Q-04).

**D-035. Выход из онбординга с открытой петлёй.**
Первая matchmade async дуэль в очереди + видимый таймер Чернил. Ожидание заполняется Лабораторией/вторым духом; матчмейкинг приоритетно сводит новичков.

## 2026-08-13 (итерации 14–17 — социальный слой, модерация, аудит; ФАЗА 1 ЗАКРЫТА)

**D-036. Модерация «мир отвергает скверну».**
Safety-класс в том же вызове парсинга (нулевая стоимость); отказ мира — легитимный тип ответа (совместим с D-031); прекаст = приватное превью модерации с нулевой ценой ложного срабатывания; ворота публикации строже приватного резолва; двухступенчатый парсинг защищает бюджет.

**D-037. Восхищения: одно в день.**
Дефицит делает похвалу весомой и создаёт дневной ритуал. Запуск — на Открытии Гримуара. Система по-прежнему нема (D-025) — восхищаются только люди.

**D-038. Театр реплеев (v1.1).**
Автокурируемая лента резолвов по КПД/новизне/восхищениям. Без человека-редактора.

**D-039. Родословная (v1.1).**
Referral-tracking в лоре генеалогии: «первое слово» + древо линий на странице ветерана. Чисто косметика, ноль экономических наград.

**D-040. Школы-знамёна (v2).**
Тег + полка сигнатур + сезонная лига школ. Внутреннего чата не будет никогда — модерационная ноша отдана внешним инструментам.

**D-041. Отклонено навсегда: ставки, кооп-каст, встроенный чат.**
Гэмблинг-риск / скоуп / модерация. Записано, чтобы будущие «а давайте» разбивались о документ.

**D-042. Уточнения финального аудита.**
(а) КПД — публичная арифметика, не системная похвала: граница D-025/D-027 зафиксирована. (б) Инициация: после N шёпотов дух подводит к осколкам — тупик невозможен. (в) Новизна для Чернил = промах инфраструктурного кэша, не отсутствие в летописи.

**ФАЗА 1 (мета-слой) ЗАКРЫТА: 17 итераций, D-001…D-042, 6 дыр найдено и заделано.**

## 2026-08-13 (итерация 18 — аудит v2; найдено 8 пунктов после «закрытия» фазы)

**D-043. Ключи эрозии = ключам открытий (кластер × среда).**
Рассинхрон систем координат устранён: заезженность фразы в одной арене не дорожит её в другой.

**D-044. Эмиссия роялти затухает с эрозией.**
Незакрытая инфляция Чернил устранена тем же механизмом, что двигает мету: чем заезженнее фраза, тем меньше капает автору. Числа → Q-08.

**D-045. Стилевые бонусы — только за механически проверяемую форму.**
Слоги/структуру считает детерминированный код. LLM-оценка красоты запрещена (граница D-025 распространена на хардкор-тир; противоречие хайку-бонуса устранено).

**D-046. Цена фиксируется в момент отправки хода.**
Эрозия между отправкой и асинхронным резолвом не трогает уплаченное. Прекаст-контракт (D-004) нерушим во времени.

**D-047. Рейтинг открывается не раньше Открытия Гримуара; название игры — Nexora.**
(а) В Безмолвии холодный кэш душил бы бюджет новизны рейтинга. (б) Q-07 закрыт: Nexora — имя продукта, «Грамматика» — кодовое имя механики.

**D-048. Язык: ввод любой, летопись едина по смыслу.**
Мультиязычные эмбеддинги объединяют переводы в одно открытие. Кросс-языковая точность — гипотеза Безмолвия (→ Q-05). UI: EN первым, RU вторым.

**D-049. Документная дисциплина.**
Найдена рассинхронизация CONCEPT.md с D-016 (устаревшая «перманентная скидка»). Правило: решение, отменяющее старое, обязано править ВСЕ упоминания в CONCEPT.md в том же коммите. CONCEPT.md — контекст для Cursor, противоречия в нём = баги в промптах.

**ФАЗА 1 ЗАКРЫТА АУДИТОМ v2: 18 итераций, D-001…D-049, 7 дыр фазы + 8 находок пост-аудита.**

## 2026-08-13 (итерации 19–22 — Фаза 2, таксономия; Q-14 закрыт)

**D-050. Таксономия = грамматика, не enum.**
Структура: {глагол, субстрат, аспекты[], цель, величина, длительность, [райдер]}. 10 глаголов × 6 субстратов × 5 целей = 300 архетипов. Пути «плоский enum» и «полная физика» отвергнуты.

**D-051. Величины — только ординальные классы.**
LLM выдаёт ярлыки {лёгкое…предельное}, {мгновенное…до рассеивания}; числа назначает код. D-002 распространён на все количественные поля.

**D-052. Аспекты — открытые теги без логики.**
Модулируют коэффициенты и визуал, никогда не ветвят правила. Открытость словаря безопасна по построению.

**D-053. Райдер: максимум один, триггеры закрыты.**
{при-движении, при-касте, при-контакте, в-конце-хода}. Комбинаторный взрыв условий отрезан.

**D-054. Резолв — фиксированные слои, не пары.**
слово → пространство → оградить → преобразить → сковать/скрыть → нанести/истощить/влить → райдеры → тик. Порядок = физика мира; лог резолва обучает слоям.

**D-055. Язык и физика — разные слои ценности.**
Летопись ключуется семантикой, движок — структурой; совпадение физики не сливает открытия. Коллапс иллюзии структурно исключён; эрозия получает клапан «новые слова для старой физики».

**D-056. Аффинность среды = модификатор цены по аспектам.**
Мета локальна по аренам; защёлкивается с D-043.

**D-057. Дисциплина заморозки.**
Глаголы/субстраты закрыты навсегда, изменения аддитивны (version в структуре), сезоны добавляют арены/аспекты — не логику.

## 2026-08-13 (итерации 23–26 — контракт LLM↔код; Q-15 закрыт)

**D-058. ПЕРЕСМОТР «дешёвого прекаста»: единственный парс, коммит по хэшу.**
Двухмодельная схема ломала D-004 (согласие с A, исполнение B). Черновик = полный разбор; коммит = хэш; повторного разбора нет. Бюджет защищает ступень-1 микроклассификатор + кэш. Формулировки в CONCEPT.md исправлены этим же коммитом (D-049).

**D-059. Схема структуры v1.**
Полей с числами нет; все закрытые enum'ы + открытые аспекты-теги + safety + confidence. Спека в COMBAT-CORE.md.

**D-060. Одна трактовка; переписывание = уточнение.**
Меню вариантов запрещено. confidence: low → подсказка. Точность формулировки — продаваемый скилл.

**D-061. Грамматика = песочница инъекций.**
Канал LLM→движок не имеет степеней свободы кроме легальных enum'ов; максимум атаки — дорогой легальный класс. D-051 ретроспективно признан решением безопасности. Гигиена: UTTERANCE-изоляция, zod, 1 repair, мета-фразы → шёпот.

**D-062. Отказы без потерь.**
Ретраи → черновик сохраняется, потерь нет. Машина состояний draft→commit(hash)→resolve; резолв — чистая идемпотентная функция.

**D-063. Канонизация кластеров.**
Первый разбор кластера = его структура навсегда; наследование без парса. Недетерминизм LLM устранён. Лор: «первое слово формирует заклинание».

**D-064. Нет RNG.**
Неопределённость только из скрытых одновременных ходов. Шахматы+покер. Честность D-028 дотянута до костей резолва.

**D-065. Нарратив — детерминированные шаблоны.**
LLM отсутствует в пути резолва. Ноль стоимости, воспроизводимость, переводимость.

## 2026-08-13 (итерации 27–30 — состояние дуэли и архитектура; Q-16, Q-17 закрыты)

**D-066. Стойкость — единственная шкала жизни.**
Мульти-полоски отвергнуты ради читаемости. 0 = поражение.

**D-067. Мана видима; разум = информационная война.**
Публичный стек = пища чтения + телеграф накоплений. скрыть/разум — маска ±класс; нанести/разум — в обход физических щитов; сковать/разум — лимит слов 12→8/6 (атака на само оружие игры, причина видима жертве).

**D-068. Единая ординальная арифметика.**
Щит поглощает ≤ своей величины, выше пробивает разницей; рассеять снимает ≤; сковать держится величиной. Одно правило — все слои.

**D-069. Пространство = состояния, не координаты.**
Якоря магов + флаг высоты + центр. Сетка отвергнута; расширение только аддитивно при доказанной нужде прототипом.

**D-070. Победа/ничья/время.**
Стойкость 0; обоюдный 0 = сплит; асинхрон 48ч/ход → сдача; синхрон 60с → пас (мана копится), два паса = сдача. Красный флаг баланса: сковать/слово.

**D-071. Сервер-авторитарность + RLS-одновременность.**
Клиент не вычисляет исходы; закоммиченный ход противника недоступен из БД до двойного коммита (политика строк). Урок CoachFlow применён превентивно.

**D-072. UX: дуэль = переписка.**
Инбокс дуэлей как чаты; резолв = сообщение мира; ввод внизу. Асинхрон получает родной паттерн мессенджера.
