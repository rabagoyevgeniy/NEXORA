# NEXORA — Журнал решений

Формат: дата — решение — обоснование. Решения не пересматриваются без записи о пересмотре.

## 2026-08-12

**D-001. Жанр: текстовая PvP-дуэль на LLM-движке («Грамматика»).**
Обоснование: единственный жанр, структурно недоступный большим студиям И совместимый с workflow «промпты с телефона в Cursor».

**D-002. LLM — переводчик, не судья.**
LLM: фраза → структура. Исход считает детерминированный код. Причина: защита от prompt injection + гарантия честности.

**D-003. Ходы одновременные, вскрытие как в покере.**
Причина: снимает латентность LLM, снимает реалтайм-нетворкинг, добавляет чтение противника.

**D-004. Прекаст обязателен.**
Черновик разбора до отправки. Причина: убивает главный риск — непредсказуемость собственных действий.

**D-005. Эрозия заклинаний.**
Частота использования фразы в мире ↑ → цена ↑. Первооткрыватель — перманентная скидка. Причина: анти-мета, встроенная в экономику.

**D-006. Лимит фразы — 12 слов.**
Причина: поэзия, а не эссе; защита от «кто напишет длиннее»; контроль стоимости инференса.

**D-007. Web-only, Vercel, React+TS+Supabase+Anthropic API.**
Причина: разработка и проверка с телефона; переиспользование паттернов Null Club / CoachFlow.

**D-008. Документация концепта живёт в этом репо, коммитит только Cursor.**
Причина: правило «один агент на репозиторий» (урок Aqua Trench). Ideation — в чате Claude, файлы переносятся промптом.

**D-009. Первая проверка фана — дуэль против ИИ-противника, не hot-seat.**
Причина: тестируется в одиночку, из любого места.
