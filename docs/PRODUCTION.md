# NEXORA — Производство (Фаза 3)

> Карта милстоунов + атомарные промпты для Cursor. Правила: D-088…D-091.
> Один промпт = одна проверяемая фича. DoD: тесты зелёные + deploy + curl URL.

## Промпты — в папке /prompts (D-101)

Каждый промпт — отдельный файл prompts/P-XXX.md. Команда для Cursor (одна строка с телефона):
`Read and execute prompts/P-XXX.md. Follow AGENTS.md.`

**Цикл проверки**: Cursor коммитит → Женьчик пересылает ответ Claude → Claude пуллит репо, читает дифф, гоняет тесты в своём контейнере → вердикт «принято» или prompts/P-XXX-fix.md. Чтение репо публично — проверка не зависит от токена.

## Правила выдачи следующих промптов

Промпты M2+ выдаются пачками после закрытия текущего милстоуна (реальность M1 уточнит M2). Запрос: «промпты M2».
