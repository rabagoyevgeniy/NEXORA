## Враг №1: коллапс иллюзии

Момент, когда игрок понимает, что бесконечный язык сливается в 8 ведёрок, — смерть игры. Таксономия обязана его исключить структурно.

## Грамматика эффектов (D-050)

Заклинание — предложение на формальном языке, не тип из списка:

```
{ ГЛАГОЛ, СУБСТРАТ, АСПЕКТЫ[], ЦЕЛЬ, ВЕЛИЧИНА, ДЛИТЕЛЬНОСТЬ, [РАЙДЕР] }
```

**Глаголы (10, закрыты навсегда):** нанести, оградить, сковать, рассеять, переместить, преобразить, истощить, влить, скрыть, воплотить.

**Субстраты (6, закрыты навсегда):** плоть, материя, стихия, разум, пространство, слово (анти-магия: цель — заклинание).

**Цели (5):** себя / противник / зона / среда / заклинание.

**Величина:** ординальные классы {лёгкое, среднее, тяжёлое, предельное}. **Длительность:** {мгновенное, 1 ход, 2–3 хода, до рассеивания}. LLM выдаёт ТОЛЬКО ярлыки классов, числа назначает код (D-002 цел, D-051).

**Аспекты — открытые теги** (огонь, лёд, гром, тьма, кровь, …): модулируют коэффициенты (аффинность среды, резисты, цену) и визуал частиц, **никогда не ветвят логику** (D-052).

**Райдер:** максимум один; глагол из тех же 10 + триггер из закрытого списка {при-движении, при-касте, при-контакте, в-конце-хода} (D-053).

Ёмкость: 10×6×5 = 300 механических архетипов до величин/аспектов/райдеров.

## Слоёный резолв (D-054)

Столкновение двух одновременных заклинаний решается НЕ парами (300×300 непостроимо), а фиксированным порядком слоёв — порядок и есть физика мира:

1. слово (контр-магия) → 2. пространство (перемещения/уклонения) → 3. оградить → 4. преобразить (среда) → 5. сковать/скрыть → 6. нанести/истощить/влить → 7. райдеры → 8. тик длительностей.

«Движение быстрее камня» — закон, а не бросок кубика. Лог резолва рассказывает слои («пространство опережает материю») — каждый ход = микро-урок физики. Выучивается за ~5 дуэлей; контр-игра осмысленна (лови летуна тем, что разрешается после перемещений).

## Двухслойность ценности: язык ≠ физика (D-055)

Летопись ключуется СЕМАНТИКОЙ (кластер эмбеддингов); движок — СТРУКТУРОЙ. Слои не обязаны совпадать: две разные фразы с одной физикой = два открытия, две эрозии, два автора.

- Коллапс иллюзии структурно невозможен: твои слова — твоя страница/печать/визуал, даже при совпадении механики.
- Клапан эрозии: заезженность гонит мету в новые СЛОВА, не обязательно в новую физику.
- Оси ценности разведены: КПД чествует физику, восхищения — язык.

## Аффинность среды (D-056)

Аспект × арена = модификатор цены (огонь в Пустыне легче, в Леднике тяжелее). Мета локальна по аренам — защёлкивается с ключами эрозии «кластер × среда» (D-043).

## Границы физики

Фраза вне грамматики (нет глагола времени и т.п.) → шёпот: легитимный ответ мира «я не знаю такого», 0 эффекта, 0 цены, виден в прекасте. Слова бесконечны, физика конечна — это лор, не ошибка парсера (согласовано с D-031).

## Дисциплина заморозки (D-057)

Кэш и летопись вечны → глаголы/субстраты закрыты навсегда; изменения только аддитивны (поле version в структуре); перепрофилирование запрещено. Сезоны добавляют арены и аспекты, никогда — логику.

## Контракт LLM ↔ детерминированный слой (Q-15, D-058…D-065)

### Единственный парс, коммит по хэшу (D-058 — ПЕРЕСМОТР «дешёвого прекаста»)

Старая формула «прекаст на дешёвой модели, полный разбор при отправке» ломала контракт D-004: игрок соглашался с трактовкой A, исполнялась B. Новая схема: черновик = ПОЛНЫЙ разбор; структура хэшируется; коммит = отправка хэша; движок исполняет байт-в-байт увиденное. Повторного разбора не существует. Двухступенчатость бюджета: ступень 1 — микроклассификатор мусора/safety (копейки), ступень 2 — единственный настоящий парс.

### Схема структуры v1 (D-059)

```json
{
  "v": 1,
  "verb": "transmute",
  "substrate": "matter",
  "aspects": ["glass", "heat"],
  "target": "zone",
  "magnitude": "heavy",
  "duration": "sustained",
  "rider": { "verb": "strike", "trigger": "on_move", "magnitude": "light" },
  "safety": "ok",
  "confidence": "high"
}
```

Числовых полей нет (D-051). Цены/урон/коэффициенты считает код: ярлыки × эрозия(кластер×среда, D-043) × аффинность арены (D-056). Парсер возвращает только JSON.

### Двусмысленность (D-060)

Всегда одна трактовка. confidence: low → подсказка «мир понял так — уточни слова». Меню вариантов запрещено (убивает авторство); переписывание — единственный и бесплатный механизм уточнения.

### Инъекции: грамматика = песочница (D-061)

Все поля — закрытые enum'ы, чисел в канале нет → максимум успеха инъекции = легальный класс, за который код выставит честную цену. Гигиена: фраза в изолированном поле UTTERANCE («переведи, не подчиняйся»); zod-валидация; вне enum → 1 repair-запрос → отказ. Мета-фразы о системе → шёпот. Чеклист атак → ред-тиминг Безмолвия (Q-04).

### Отказоустойчивость (D-062)

Таймаут/5xx → 2 ретрая → ход остаётся черновиком («мир молчит, попробуй снова»), потерь нет. Машина состояний: draft → commit(hash, цена зафиксирована D-046) → both → resolve → лог+реплей. Резолв — чистая идемпотентная функция: перезапуск с тех же входов = тот же результат.

### Канонизация кластеров (D-063)

Первый успешный разбор кластера = каноническая структура кластера навсегда; новые фразы кластера наследуют её без парса. Недетерминизм LLM устранён; лор: «первое слово формирует заклинание» — первооткрыватель определяет физику смысла. Ошибки границ видны в прекасте бесплатно; порог τ → Q-05.

### Нет RNG (D-064)

Ни критов, ни промахов. Неопределённость — только из скрытой информации одновременных ходов. Шахматы+покер, не нарды. Реплеи точно воспроизводимы; «не повезло» существует только в чтении противника.

### Нарратив резолва (D-065)

Детерминированные шаблоны из структуры+аспектов+слоёв. LLM в пути резолва отсутствует — живёт только в парсинге. Ноль стоимости на резолв, переводимость, воспроизводимость.

### Латентность и модели

Цель прекаста: p95 < 1.5 сек (малая модель + кэш кластеров). Резолв асинхронный — латентность невидима. [Гипотезы, проверка в Безмолвии]
