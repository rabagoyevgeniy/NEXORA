# NEXORA — Боевое ядро (Фаза 2)

> Статус: **ФАЗА 2 ЗАКРЫТА (аудит v3)** — итерации 19–33, D-050…D-085. Верификация гипотез и красных флагов — в Безмолвии.
> Связанные файлы: CONCEPT.md (мета-слой), DECISIONS.md (журнал), OPEN-QUESTIONS.md.

## Враг №1: коллапс иллюзии

Момент, когда игрок понимает, что бесконечный язык сливается в 8 ведёрок, — смерть игры. Таксономия обязана его исключить структурно.

## Грамматика эффектов (D-050)

Заклинание — предложение на формальном языке, не тип из списка:

```
{ ГЛАГОЛ, СУБСТРАТ, АСПЕКТЫ[], ЦЕЛЬ, ВЕЛИЧИНА, ДЛИТЕЛЬНОСТЬ, [РАЙДЕР] }
```

**Глаголы (10, закрыты навсегда):** нанести, оградить, сковать, рассеять, переместить, преобразить, истощить, влить, скрыть, воплотить.

**Субстраты (6, закрыты навсегда):** плоть, материя, стихия, разум, пространство, слово (анти-магия: цель — заклинание).

**Цели (5):** себя / противник / зона / среда / заклинание.

**Величина:** ординальные классы {лёгкое, среднее, тяжёлое, предельное}. **Длительность:** {мгновенное, 1 ход, 2–3 хода, до рассеивания}. LLM выдаёт ТОЛЬКО ярлыки классов, числа назначает код (D-002 цел, D-051).

**Аспекты — открытые теги** (огонь, лёд, гром, тьма, кровь, …): модулируют коэффициенты (аффинность среды, резисты, цену) и визуал частиц, **никогда не ветвят логику** (D-052).

**Райдер:** максимум один; глагол из тех же 10 + триггер из закрытого списка {при-движении, при-касте, при-контакте, в-конце-хода} (D-053).

Ёмкость: 10×6×5 = 300 механических архетипов до величин/аспектов/райдеров.

## Слоёный резолв (D-054)

Столкновение двух одновременных заклинаний решается НЕ парами (300×300 непостроимо), а фиксированным порядком слоёв — порядок и есть физика мира:

1. слово (контр-магия) → 2. пространство (перемещения/уклонения) → 3. оградить → 4. преобразить (среда) → 5. сковать/скрыть → 6. нанести/истощить/влить → 7. райдеры → 8. тик длительностей.

«Движение быстрее камня» — закон, а не бросок кубика. Лог резолва рассказывает слои («пространство опережает материю») — каждый ход = микро-урок физики. Выучивается за ~5 дуэлей; контр-игра осмысленна (лови летуна тем, что разрешается после перемещений).

## Двухслойность ценности: язык ≠ физика (D-055)

Летопись ключуется СЕМАНТИКОЙ (кластер эмбеддингов); движок — СТРУКТУРОЙ. Слои не обязаны совпадать: две разные фразы с одной физикой = два открытия, две эрозии, два автора.

- Коллапс иллюзии структурно невозможен: твои слова — твоя страница/печать/визуал, даже при совпадении механики.
- Клапан эрозии: заезженность гонит мету в новые СЛОВА, не обязательно в новую физику.
- Оси ценности разведены: КПД чествует физику, восхищения — язык.

## Аффинность среды (D-056)

Аспект × арена = модификатор цены (огонь в Пустыне легче, в Леднике тяжелее). Мета локальна по аренам — защёлкивается с ключами эрозии «кластер × среда» (D-043).

## Формула цены (D-082, канонический порядок)

```
цена = ceil( база[глагол][величина] × аффинность(аспекты, арена) )
       + налог_длительности + налог_райдера
       + ступень_эрозии(кластер × арена)   // может быть ОТРИЦАТЕЛЬНОЙ с полом: Голод мира (D-098),
         // категории (субстрат × аспект × арена), которых мир давно не слышал, дешевеют
       + ступень_утомления(кластер, дуэль)
```

Порядок фиксирован (детерминизм). **Прекаст показывает разложение** («7 = 4 база + 1 длительность + 2 эрозия») — игрок видит, почему дорого; экономика обучает через интерфейс.

## Щиты: канал воздействия (D-084)

Субстрат удара = КАНАЛ («чем бьют»). Щит ловит только свой канал; универсального щита нет — выбор субстрата щита = ставка на чтение противника. Аспектные модификаторы щитов (лёд против огня) — НЕ в MVP, флаг на потом.

## Маска разума: конкретика (D-083)

скрыть/разум: лёгкое = ложь о Голосе ±2; среднее = ±4; тяжёлое = Голос показывается как «?». Ложь, не туман. Эффекты маскируются по величине эффекта скрытия (≤ его класса).

## Политика дичи (D-079, D-080)

Мир НЕ цензурирует творческий абсурд — он его КОНВЕРТИРУЕТ: любая фраза маппится в физику грамматики («утка» → преобразить/плоть), прекаст показывает трактовку. Визуал — только из библиотеки известных примитивов аспектов; неизвестный аспект → обобщённые аркановые частицы. Мем живёт в тексте фразы на реплее; мир держит тон в логе и картинке. Эрозия уценяет заезженные мемы сама.

Жёсткие лимиты ввода: 12 слов И 120 символов. Ворота публикации (расширение D-036): в летопись/ленты/шаринг не проходят фразы с реальными именами, URL, хэндлами. Приватный резолв при этом работает. Поп-культурные заклинания легальны как кластеры; юр-осторожность → Q-19.

## Границы физики

Фраза вне грамматики (нет глагола времени и т.п.) → шёпот: легитимный ответ мира «я не знаю такого», 0 эффекта, 0 цены, виден в прекасте. Слова бесконечны, физика конечна — это лор, не ошибка парсера (согласовано с D-031).

## Дисциплина заморозки (D-057)

Кэш и летопись вечны → глаголы/субстраты закрыты навсегда; изменения только аддитивны (поле version в структуре); перепрофилирование запрещено. Сезоны добавляют арены и аспекты, никогда — логику.

## Контракт LLM ↔ детерминированный слой (Q-15, D-058…D-065)

### Единственный парс, коммит по хэшу (D-058 — ПЕРЕСМОТР «дешёвого прекаста»)

Старая формула «прекаст на дешёвой модели, полный разбор при отправке» ломала контракт D-004: игрок соглашался с трактовкой A, исполнялась B. Новая схема: черновик = ПОЛНЫЙ разбор; структура хэшируется; коммит = отправка хэша; движок исполняет байт-в-байт увиденное. Повторного разбора не существует. Двухступенчатость бюджета: ступень 1 — микроклассификатор мусора/safety (копейки), ступень 2 — единственный настоящий парс.

### Схема структуры v1 (D-059)

```json
{
  "v": 1,
  "verb": "transmute",
  "substrate": "matter",
  "aspects": ["glass", "heat"],
  "target": "zone",
  "magnitude": "heavy",
  "duration": "sustained",
  "rider": { "verb": "strike", "trigger": "on_move", "magnitude": "light" },
  "safety": "ok",
  "confidence": "high"
}
```

Числовых полей нет (D-051). Цены/урон/коэффициенты считает код: ярлыки × эрозия(кластер×среда, D-043) × аффинность арены (D-056). Парсер возвращает только JSON.

### Двусмысленность (D-060)

Всегда одна трактовка. confidence: low → подсказка «мир понял так — уточни слова». Меню вариантов запрещено (убивает авторство); переписывание — единственный и бесплатный механизм уточнения.

### Инъекции: грамматика = песочница (D-061)

Все поля — закрытые enum'ы, чисел в канале нет → максимум успеха инъекции = легальный класс, за который код выставит честную цену. Гигиена: фраза в изолированном поле UTTERANCE («переведи, не подчиняйся»); zod-валидация; вне enum → 1 repair-запрос → отказ. Мета-фразы о системе → шёпот. Чеклист атак → ред-тиминг Безмолвия (Q-04).

### Отказоустойчивость (D-062)

Таймаут/5xx → 2 ретрая → ход остаётся черновиком («мир молчит, попробуй снова»), потерь нет. Машина состояний: draft → commit(hash, цена зафиксирована D-046) → both → resolve → лог+реплей. Резолв — чистая идемпотентная функция: перезапуск с тех же входов = тот же результат.

### Канонизация кластеров (D-063)

Первый успешный разбор кластера = каноническая структура кластера навсегда; новые фразы кластера наследуют её без парса. Недетерминизм LLM устранён; лор: «первое слово формирует заклинание» — первооткрыватель определяет физику смысла. Ошибки границ видны в прекасте бесплатно; порог τ → Q-05.

### Нет RNG (D-064)

Ни критов, ни промахов. Неопределённость — только из скрытой информации одновременных ходов. Шахматы+покер, не нарды. Реплеи точно воспроизводимы; «не повезло» существует только в чтении противника.

### Нарратив резолва (D-065)

Детерминированные шаблоны из структуры+аспектов+слоёв. LLM в пути резолва отсутствует — живёт только в парсинге. Ноль стоимости на резолв, переводимость, воспроизводимость.

### Латентность и модели

Цель прекаста: p95 < 1.5 сек (малая модель + кэш кластеров). Резолв асинхронный — латентность невидима. [Гипотезы, проверка в Безмолвии]

## Модель состояния дуэли (Q-17, D-066…D-070)

**Стойкость** — единственная шкала жизни (воля держать форму; 0 = поражение). Пять полосок отвергнуты: читаемость — король.

**Голос видима обоим** (как стек в покере): чтение запаса = скилл; накопление на предельное = телеграф и окно контр-игры.

**Разум = война за информацию** (субстрат обрёл механику):
- скрыть/разум — маска состояния: ложь о Голосе ±2/±4/«?» по величине (конкретика в D-083), эффекты маскируются ≤ класса скрытия;
- нанести/разум — психический урон в обход физических щитов (ловится оградить/разум);
- влить/разум — снять с себя ментальное;
- **сковать/разум — связанный язык: лимит слов противника 12→8 (тяжёлое → 6)** на длительность. Атака на само оружие игры. Причина видима на поле ввода жертвы.

**Кривые** [числа — гипотезы → Q-08; скелет — решение]: Голос старт 6, +3/ход, кап 12; цены классов 2–3 / 4–6 / 7–9 / 10–12; Стойкость ~20; целевая длина 6–10 ходов. Следствия по построению: нет блицкрига 1-го хода; предельное = 2 хода накопления на глазах.

## Правила внутри слоёв (Q-16, D-068)

**Единая ординальная арифметика** на все взаимодействия:
- Щит поглощает свою величину и ниже (при совпадении субстрата/аспекта); выше — пробивает РАЗНИЦЕЙ (тяжёлое сквозь средний щит = лёгкое).
- Рассеять снимает свою величину и ниже.
- Сковать блокирует глаголы своего субстрата, держится своей величиной.
Одно сравнение — все слои.

**Пространство = состояния, не координаты (D-069)**: якорь каждого мага + флаг высоты + центр для воплощённых преград. Зональный эффект вешается на якорь; перемещение = покинуть якорь; полёт уклоняет от наземного, открыт стихийному. Сетки нет; расширение только аддитивно при доказанной нужде.

## Победа и время (D-070)

Стойкость 0 = поражение; обоюдный 0 в одновременном резолве = честная ничья (сплит). Асинхрон: 48 ч/ход, просрочка = сдача. Синхрон: 60 с/ход, просрочка = пас (Голос копится), два паса подряд = сдача.

**Внутридуэльное утомление (D-076)**: повтор той же фразы (кластера) в одной дуэли — +1 класс цены за каждое повторение. Анти-стал лечения, анти-спам победной фразы, принудительная вариативность. Глобальные сигнатуры не спасают от локального утомления — усталость слов честна для всех.

**Воплощённые сущности (D-075)**: барьер = щит для обоих (та же ординальная арифметика), hazard = условный удар на якоре. Новых правил нет.

**Печать = кластер × среда (D-074)**: подписанное в Пустыне не действует в Леднике — там отдельное открытие. Слоты считают пары.

**Экономика черновиков (D-073)**: черновики по известным кластерам — бесплатно и безлимитно (кэш); новые — N промахов кэша/ход, дальше кулдаун. Цена входит в хэш черновика с TTL ~10 мин; после TTL черновик видимо обновляет цену. Бюджет «3 новых/дуэль» считает только коммиты.

**Красные флаги баланса** (приоритетные тесты Безмолвия): сковать/слово (запрет контр-магии — предельная цена, короткая длительность, снимается рассеиванием); стилевая скидка хардкора (в MVP бонус формы КОСМЕТИЧЕСКИЙ — ореол/отметка, D-078).

## Пульс боя (D-103) — против монотонности

1. **«Противник подбирает слова…»** — индикатор набора в синхроне (метафора мессенджера в бою).
2. **Вскрытие как казнь**: своя фраза → вражеская ПЕЧАТАЕТСЯ ПО БУКВАМ (~3 сек нарастания) → столкновение. Печатающаяся фраза = анимация замаха.
3. **Экран боится**: Стойкость ≤ порога → виньетка, приглушение, «Мир слышит тебя всё тише…». Детерминировано.
4. **Минимальный звук** (пересмотр молчаливого «без аудио»): 5–6 SFX — гул мира, вдох вскрытия, сердцебиение, удар, шёпот. Скоуп ~день.
5. **«Непрерванная речь»**: видимая серия побед (пламя на странице мага), гаснет от одного поражения. Loss aversion без касания экономики/честности.
6. **«На последнем дыхании»** [КРАСНЫЙ ФЛАГ, тест Безмолвия]: Стойкость ≤ 3 → лимит слов 16, раз за дуэль, публично и симметрично (Закон 5 цел). Перед концом говорят самое важное. Драматургия камбэка: простор речи, не сила.

Структурная страховка от монотонности: эрозия + утомление + Голод двигают мету принудительно; покерное вскрытие делает каждый ход ставкой.

## Реакции: угроза, рефлекс, прессинг (D-104, D-105)

**Замах Предельного (D-104, красный флаг)**: предельные заклинания двухходовые — ход замаха (угроза ВИДНА противнику: «воздух дрожит…») → ход удара. Полноценная реакция целым ходом с прекастом: уклонение / щит канала / рассеять сам замах (цель «заклинание»). Предельное = драматургический сет-пис, не внезапная нюка. Работает в асинхроне. Синергия с видимым Голосом.

**Заготовленное слово** (переименование существующего): райдеры с триггерами и стоящие щиты = авторские рефлексы мага. Реакция в мире речи — слово, сказанное заранее.

**Блиц (D-105)**: опциональный синхрон с ходом 20 сек (парс укладывается; осколки — спасение под таймером). Не успел — пас (D-070): стоящие щиты работают, остальное — полной силой, БЕЗ крита (D-064 незыблем).

**Отклонено навсегда**: QTE-окна секундного масштаба (ломают асинхрон D-020 и прекаст/Закон 5), карточки готовых реакций (система не пишет за игрока, D-029/D-060), LLM-оценка «успел ли по времени» (судья вне D-002), криты за просрочку (D-064). Частичные исходы («задело руку») уже детерминированы слоями/арифметикой + шаблонами D-065.

## Раны и память боя (D-106) [красный флаг: раневая спираль]

**Очаги** (закрытый enum): Опора (подвижность) / Хват (физ. воздействие) / Взор (восприятие). Удар может объявить очаг (прицельность). Рана = длящийся эффект плоти; ОДНО правило: пока живёт — глаголы её семейства дорожают на класс (Опора→пространство; Хват→физические; Взор→искажение наблюдения). Лечение: влить/рассеять; держится величиной.

**Память следа**: каждый длящийся эффект хранит {фраза-источник, ход}; при влиянии на действие шаблон делает детерминированный колбэк («…рана от "ледяного кинжала" (ход 3) сковала опору»).

**Падение как банкротство**: рана удорожила глагол → не хватило Голоса → действие срывается → «Раненая опора подвела — рывок захлебнулся». Детерминировано; ни кубика, ни судьи.

Страховки спирали: налог длительности атакующему, «На последнем дыхании» (D-103), доступное лечение. Внедрение — v1.1 (после гейта фана).

## Часы угрозы и двойное время (D-107)

**Виртуальное время** (длительность действия в мире) и **реальное окно решения** разделены. Окно вычисляет ТОЛЬКО детерминированная таблица из полей структуры (величина/глагол/замах/полёт/теги арены) — LLM к времени не допускается.

Где живёт переменное окно: ответ на Замах Предельного в синхроне (пример: предельное в упор — 20с; дальняя глыба — 45с) и масштабирование ходов Блица. Асинхрон — константа («один ход»): переменные таймеры структурно несовместимы с ядром retention. Просрочка = пас, полный урон, без критов.

**Нарративное время**: классы → слова времени (лёгкое «за удар сердца», среднее «за вдох», тяжёлое «за три вдоха», предельное «пока собирается буря») в шаблонах лога. Мир дышит временем без новой механики.

**Отклонено навсегда**: LLM-вычисление окон; переменные таймеры в асинхроне; оценка «успел бы в реальности» сверх факта истечения таймера.

## Хардening-раунд (итерации 48–57, D-108…D-112)

- **Печать = потолок** (D-108): автор платит min(база, текущая цена); Голод-скидка доступна и ему.
- **Канал произнесения** (D-109): в ход выпуска Предельного лимит замахнувшегося = 6 слов; выпуск автоматичен (слой 6); рассеивание замаха срывает выпуск, Голос сгорает.
- **Взор-рана = маска D-083** той же величины (переиспользование, ноль новых правил).
- **Лимиты слов аддитивны** (D-110): «На последнем дыхании» = +4 к текущему, пол 4. Связанный язык не стирается клатчем.
- **Серия — только рейтинговая** (D-110): казуал/Эхо пламя не трогают; ничья замораживает серию. (Спасение параллельного асинхрона.)
- **Летопись кросс-языка** (D-111): первое слово — оригинал крупно + курсивный перевод-толкование. Первые слова не переводятся — толкуются.
- **Очаг — аддитивное поле v2** (locus, опционально, default корпус); заморозка D-057 = запрет менять, не запрет аддитивно расширять. Рана обязана иметь длительность → существующий налог, без нового.
- **Блиц = экзамен эрудиции** (переосмысление): обычный темп — творчество, Блиц — знание Гримуара + скорость осколков. Два вида мастерства.
- **Кураторские затравки** (D-112): ~100 ходовых фраз канонизируются вручную до запуска — физика частого фундамента ручной работы; летопись не тронута.
- **Гонка Первого Слова**: первенство = timestamp резолва + unique(кластер×среда); проигравший — «второе эхо» с отметкой. **Прекаст-UI**: топ-3 слагаемых + «прочее», полное разложение по тапу.

## Находка плейтеста №1 (D-113): прогноз воздействия в прекасте

Симптом (живая сессия): игрок купил ПРЕДЕЛЬНОЕ за 11 Голоса, не понимая, что это ≈ −10 Стойкости при чистом попадании → «на нас луна упала, где логика?!». Разрыв между нарративным масштабом имени и механическим классом.

Фикс: прекаст показывает **прогноз чистого воздействия** («до −10 Стойкости; чужие щиты срежут по разнице классов»). Детерминировано; скрытую информацию не раскрывает (показывается потолок без знания щитов противника).

Афоризм мира (в Инициацию, бит Отзвука): **«Именем зовут — Голосом платят»** — имя даёт облик, уплаченное даёт силу; буквализм слов сломал бы мир («он умирает» за два слова).

## Находки плейтеста №2 (D-114) — «почему скучно»

Диагноз живой сессии: (1) мир говорит «нет» чаще «да» — 2 действия на 7 реплик игрока; (2) бухгалтерия хода ~10 инфоблоков вместо 3; (3) путь к предельному = пассивные пасы; (4) ноль ставок в Отголоске; (5) противник без давления.

Фиксы:
1. **Однострочный черновик по умолчанию** («ГЛАГОЛ аспект → цель · ≈ эффект · цена — произнести?»); полнота по тапу. Радикализация D-113/итерации 57.
2. **«Исполняй, потом учи»**: первый час игры мир кастует лучшую валидную трактовку сразу (зрелище), поправки — одной строкой после. Прекаст-контракт не тронут — сжата подача.
3. Экономический констрейнт Q-08: **≤ 1 вынужденного паса до предельного**.
4. **Пас = «вдох»** [красный флаг]: микро-действие (лёгкая стойка корпуса), не дыра в бою.
5. **Первый бой обязан содержать вражеский Замах** — игрок чувствует нависшее предельное на себе.
6. **Стрип и звук — несущие стены, не полировка**: текстовый нарратив в одиночку образ не тащит.
7. Бюджет реплик наставника после Инициации: **≤ 15 слов на ход**.
8. Гейт фана НЕ валиден в чат-прототипе — только на билде M4 (стрип+звук+живой темп).
