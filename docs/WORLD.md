# SLOVO — Мир НЕКСОРА и Голос (Фаза 4)

> Игра: **SLOVO**. Мир: **НЕКСОРА** (D-095). Слоган: **«В начале было Слово» / "In the beginning was the Word"** (D-092).
> Статус: итерации 38–41.

## Космология: три кита (проявлены из механик, не придуманы поверх)

1. **Мир слушает.** Реальность соткана из произнесённого; магия = речь, которую мир расслышал. (← кор-луп)
2. **Гримуар — память мира, не книга.** Сказанное впервые становится законом навсегда; мир не умеет забывать первых. (← канонизация D-063, вечная летопись)
3. **Слова устают.** Повторённое мир слышит глуше; слова истираются, как монеты; мир жаден до новизны. (← эрозия D-005, утомление D-076)

## Тон

- Благоговейно-нейтральный: собственный миф о языке, БЕЗ божеств, доктрин и изображений сакрального. Слоган — резонанс с архетипом, не вероучение. В мире нет Бога — есть безличный **Слух мира**.
- Стоицизм против пафоса: мир невозмутимо переводит юмор на свой язык (D-079); серьёзная интерпретация утки смешнее утки — это осознанный комедийный приём.

## Голос

Голос Инициации и системных реплик — **Слух мира**: древний, терпеливый, чуть усталый от тысячелетий повторов, оживающий при новизне. Персона духа-наставника — производная этого голоса (детали → итерации фазы, Q-06/Q-22).

## Драматургия запуска (D-093)

В начале было **Безмолвие** (предсезон: мир молчит, летопись запечатана) — потом было **Слово**. Событие запуска: **«Первое Слово»** (бывш. «Открытие Гримуара»). Контент-кампания = обратный отсчёт до Первого Слова.

## Семь Законов Нексоры (D-096)

Вся механика, сжатая в пословицы. Лор = туториал = маркетинг. Дух произносит их в Инициации по одному, делом показывая каждый; Кодекс Законов — первая страница Гримуара.

1. **«Мир слушает.»** — всё есть речь; любой ввод получает ответ (D-031).
2. **«Первое слово — закон.»** — сказанное впервые формирует явление навсегда, с именем (D-063).
3. **«Слова устают.»** — повторённое слышится глуше и дорожает (эрозия, утомление).
4. **«Забытое дешевеет.»** — мир скучает по несказанному; голод мира (D-098).
5. **«Мир не лжёт.»** — черновик = исполнение; ни кубиков, ни подкруток, ни жалости (D-004/058/064/028).
6. **«Движение быстрее камня.»** — строгий черёд событий: слои резолва (D-054).
7. **«Мир отвергает скверну.»** — есть слова, которые Нексора не произнесёт (D-036).

## Нексора — обучающийся мир (D-097)

Стержень: **мир учится открыто и по закону** — никаких тихих подкруток (Закон 5). Четыре контура:
1. **Экономический** (реал-тайм, по правилам): эрозия + Голод мира (D-098) — самобалансирующаяся экономика в обе стороны; публичные индикаторы голода = муза на данных (D-029 цел: категории, не фразы).
2. **Парсерный** (батчи, версии): переписанные черновики = бесплатная разметка → банк few-shot примеров; старые кластеры защищены канонизацией; Безмолвие — родильный дом контура.
3. **Балансовый** (сезонно, публично): телеметрия → сдвиги коэффициентов ТОЛЬКО на границах сезонов или объявленными мировыми событиями. Мир меняется вслух, как эррата.
4. **Духи — зеркало меты**: ИИ кастует из живого Гримуара (известные кластеры, ноль инференса) → противники эволюционируют с метой без обучения моделей.
