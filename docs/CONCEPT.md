# NEXORA — Концепт (актуальная версия)

> Статус: итерации 4–7 (мета-слой: прогрессия, удержание, ценность аккаунта). Фаза мета-слоя НЕ закрыта.
> Этот файл — единственный источник правды по концепту. Обновляется после каждой итерации обсуждения.

## Одной строкой

PvP-дуэль магов, где вместо кнопок скиллов — строка ввода: игрок пишет заклинание словами, LLM переводит фразу в строгую игровую структуру, детерминированный движок честно её исполняет.

## Почему это не сможет повторить большая студия

- Баланс невозможно гарантировать → нет киберспорта, нет обещания честности.
- Свободный текстовый ввод → модерация, сертификация сторов, юридический риск.
- Плавающая себестоимость матча (инференс) вместо нулевой.
- Матчи невоспроизводимы → нечего показать в трейлере как «геймплей».

Это структурная стена для корпораций и среда обитания для соло-разработчика.

## Кор-луп (один ход)

1. Экран дуэли: маг слева, маг справа. У игрока N маны и поле ввода (лимит 12 слов).
2. Игрок пишет фразу («Песок под его ногами превращается в стекло»).
3. **Прекаст**: перед отправкой игрок видит черновик разбора — тип, цель, примерная сила, точная цена маны. Бесплатно, мгновенно. Можно переформулировать. Отправка = согласие с трактовкой.
4. Ходы одновременные, вскрываются вместе (покерная модель).
5. LLM → строгая структура: {тип воздействия, цель, длительность, урон, побочные эффекты, стоимость}.
6. Детерминированный слой валидирует и резолвит: применимость к среде, ресурсы, резисты, взаимодействие двух заклинаний.
7. Результат хода + автогенерируемая векторная анимация резолва.

**Ключевой принцип**: LLM никогда не решает исход и не выдаёт числа напрямую — только структуру, которую пересчитывает код. Хаос на входе, честность на выходе.

## Скилл игрока

Не реакция, не APM. Поиск формулировок с максимальным эффектом при минимальной цене + чтение противника. Эксплойты языка — не баг, а содержание игры.

## Гримуар (социальное ядро)

- Каждая фраза, произнесённая впервые в мире, записывается в общий кодекс навсегда с именем автора.
- Первооткрыватель получает статус + перманентную роялти-скидку на своё заклинание.
- Известная фраза → закэшированный эффект → нулевая стоимость инференса. Платим LLM только за настоящую новизну (нормализация через эмбеддинги, не строковый матчинг).

## Эрозия заклинаний (анти-мета)

Чем чаще фраза используется в мире, тем дороже она стоит. Лор: заезженные слова теряют силу, магия питается новизной. Механика: сходимость к мете автоматически делает мету дорогой → игра структурно заставляет творить. Кривая эрозии — предмет тюнинга.

## Три уровня ввода (порог входа)

| Уровень | Ввод | Аудитория |
|---|---|---|
| Казуал | Свайп по тегам-осколкам (стихия + действие + цель), движок собирает фразу | Массовый игрок |
| Мидкор | Пишет сам, лимит 12 слов | Ядро |
| Хардкор | Пишет сам + модификаторы стиля (хайку-заклинание = бонус) | Стримеры, контент |

Все три уровня попадают в один движок — баланс общий.

## Виральность

- Реплей хода = автогенерируемая гифка: минималистичный вектор, две фигуры, эффекты частиц по типам из структуры, поверх — текст заклинаний. Шеринг одной кнопкой.
- Формат мема: «он написал ЭТО → произошло ВОТ ЧТО».
- Гримуар как лента открытий: охота за пустыми областями смыслового пространства.
- Публичная война разработчика с игроками, ломающими движок языком, — контент для канала Самурай AI.

## Технические рамки (продиктованы workflow)

Разработка: Cursor, промптами с телефона, свободное время. Отсюда жёстко:

- **Web-only**: деплой Vercel, проверка — открыл URL с телефона.
- **Текст/UI, ноль графических ассетов** (кроме процедурных частиц).
- **Пошагово, не реалтайм** (одновременные ходы снимают и латентность LLM ~2 сек).
- **Атомарные итерации**: один промпт = одна проверяемая фича.
- Стек: React + TypeScript + Supabase + Anthropic API (совпадает с Null Club / CoachFlow — переиспользование паттернов).

## Экономика и монетизация

**Стержневой принцип: деньги покупают пространство для творчества, не силу.**

- **Мана** — только внутри боя, не покупается никогда.
- **Чернила** — мета-ресурс, тратится на произнесение *нового* заклинания (нет в Гримуаре). Известные заклинания бесплатны (кэш). Чернила = зеркало себестоимости инференса: игровой ресурс совпадает с юнит-экономикой.

| Режим | Мана | Новые заклинания | Чернила |
|---|---|---|---|
| Рейтинг | в бою | 3/дуэль, бесплатно, у всех | не действуют |
| Казуал | в бою | из дневного запаса | тратятся |
| Лаборатория (песочница, манекен) | ∞ | сколько есть Чернил | основная топка |

**Анти-P2W**: в рейтинге бюджет новизны уравнен для всех, Чернила не работают. Платящий получает из Лаборатории только знание (проверенные формулировки) — легитимное преимущество уровня «купить шахматный учебник».

**Роялти чернилами**: твоё заклинание используют другие → капают Чернила. Талантливый творец играет бесплатно — осознанная витрина модели.

**Защита кошелька разработчика**: дневной лимит Чернил = потолок расходов на игрока; прекаст на дешёвой модели; полный разбор только при отправке.

**Открытие только кровью**: заклинание регистрируется в Гримуаре при первом эффективном применении в матче против человека, не в Лаборатории. + Кластеризация эмбеддингов против сквоттинга вариаций.

**Источники дохода**: подписка «Кодекс» ~$6/мес (Чернила для Лаборатории, косметика, страница автора) + разовая косметика (анимации резолва, сигилы, оформление Гримуара, титулы) + сезонные тома.

## Прогрессия и чувство роста

**Рост в ширину, не в высоту**: ветеран не бьёт больнее — у него больше выразительных средств.

**Сигнатуры** (замена роялти-скидки из ранней версии D-005, см. D-016):
- Автор «подписывает» своё открытие → для него оно навсегда стоит базовую цену, иммунитет к эрозии. Лор: слово слушается того, кто произнёс его первым.
- Слотов печатей мало: 3 на старте → 7–9 максимум. Растут только игрой (уровень мага), не деньгами.
- Набор сигнатур = билд-идентичность мага. Тебя читают и узнают по печатям.
- Расширение слотов = ощутимая прогрессия без роста цифр урона.

## Ценность аккаунта

Аккаунт = библиотека и репутация: летопись открытий (вечна), активные сигнатуры, роялти-поток, титулы, архив реплеев, рейтинг.

**Решение проблемы позднего игрока** (пространство открытий исчерпаемо):
1. **Контекстные открытия**: открытие = заклинание × среда. Новая арена каждый сезон = новая целина. Среды обязательны (закрывает направление Q-02).
2. **Выцветание**: заклинание без использования целый сезон теряет активную печать и может быть переоткрыто. Летопись первого автора вечна; власть циклична. Два слоя UI: «Открыто [имя], сезон N» (навсегда) + текущий держатель печати.
3. **Локальные первенства**: первый в лиге / сезоне / арене — новичок конкурирует в своём слое.

## Удержание

- **Ядро — асинхронные дуэли** («шахматы по переписке»): 3–5 живых дуэлей одновременно, ход противника = органическая нотификация. Одновременные ходы (D-003) делают асинхрон технически тривиальным и решают матчмейкинг малой базы на старте. Синхронная дуэль = тот же движок в быстром темпе (Q-03 закрыт).
- Дневной якорь: запас Чернил + дневной контракт (v1.1).
- Недельный: турнир (v1.2). Сезонный: новый том + новая арена.
- Анти-пуш-усталость: агрегация нотификаций, тихие часы по умолчанию.
- **MVP retention = только асинхрон + дневные Чернила.** Остальное после живой базы (анти-scope-creep).

## Эволюция механики без патчей

- Эрозия непрерывно двигает мету сама — игра эволюционирует без патч-нотов.
- Сезонная арена = новое пространство открытий (твик тегов среды, не контент-производство).
- Мировые события («Затмение: ментальная магия −20% на неделю») = твик одного коэффициента детерминированного слоя = иллюзия контент-конвейера большой студии.
