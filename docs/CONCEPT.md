# NEXORA — Концепт (актуальная версия)

> Статус: итерация 2. Концепция в разработке, MVP не начат.
> Этот файл — единственный источник правды по концепту. Обновляется после каждой итерации обсуждения.

## Одной строкой

PvP-дуэль магов, где вместо кнопок скиллов — строка ввода: игрок пишет заклинание словами, LLM переводит фразу в строгую игровую структуру, детерминированный движок честно её исполняет.

## Почему это не сможет повторить большая студия

- Баланс невозможно гарантировать → нет киберспорта, нет обещания честности.
- Свободный текстовый ввод → модерация, сертификация сторов, юридический риск.
- Плавающая себестоимость матча (инференс) вместо нулевой.
- Матчи невоспроизводимы → нечего показать в трейлере как «геймплей».

Это структурная стена для корпораций и среда обитания для соло-разработчика.

## Кор-луп (один ход)

1. Экран дуэли: маг слева, маг справа. У игрока N маны и поле ввода (лимит 12 слов).
2. Игрок пишет фразу («Песок под его ногами превращается в стекло»).
3. **Прекаст**: перед отправкой игрок видит черновик разбора — тип, цель, примерная сила, точная цена маны. Бесплатно, мгновенно. Можно переформулировать. Отправка = согласие с трактовкой.
4. Ходы одновременные, вскрываются вместе (покерная модель).
5. LLM → строгая структура: {тип воздействия, цель, длительность, урон, побочные эффекты, стоимость}.
6. Детерминированный слой валидирует и резолвит: применимость к среде, ресурсы, резисты, взаимодействие двух заклинаний.
7. Результат хода + автогенерируемая векторная анимация резолва.

**Ключевой принцип**: LLM никогда не решает исход и не выдаёт числа напрямую — только структуру, которую пересчитывает код. Хаос на входе, честность на выходе.

## Скилл игрока

Не реакция, не APM. Поиск формулировок с максимальным эффектом при минимальной цене + чтение противника. Эксплойты языка — не баг, а содержание игры.

## Гримуар (социальное ядро)

- Каждая фраза, произнесённая впервые в мире, записывается в общий кодекс навсегда с именем автора.
- Первооткрыватель получает статус + перманентную роялти-скидку на своё заклинание.
- Известная фраза → закэшированный эффект → нулевая стоимость инференса. Платим LLM только за настоящую новизну (нормализация через эмбеддинги, не строковый матчинг).

## Эрозия заклинаний (анти-мета)

Чем чаще фраза используется в мире, тем дороже она стоит. Лор: заезженные слова теряют силу, магия питается новизной. Механика: сходимость к мете автоматически делает мету дорогой → игра структурно заставляет творить. Кривая эрозии — предмет тюнинга.

## Три уровня ввода (порог входа)

| Уровень | Ввод | Аудитория |
|---|---|---|
| Казуал | Свайп по тегам-осколкам (стихия + действие + цель), движок собирает фразу | Массовый игрок |
| Мидкор | Пишет сам, лимит 12 слов | Ядро |
| Хардкор | Пишет сам + модификаторы стиля (хайку-заклинание = бонус) | Стримеры, контент |

Все три уровня попадают в один движок — баланс общий.

## Виральность

- Реплей хода = автогенерируемая гифка: минималистичный вектор, две фигуры, эффекты частиц по типам из структуры, поверх — текст заклинаний. Шеринг одной кнопкой.
- Формат мема: «он написал ЭТО → произошло ВОТ ЧТО».
- Гримуар как лента открытий: охота за пустыми областями смыслового пространства.
- Публичная война разработчика с игроками, ломающими движок языком, — контент для канала Самурай AI.

## Технические рамки (продиктованы workflow)

Разработка: Cursor, промптами с телефона, свободное время. Отсюда жёстко:

- **Web-only**: деплой Vercel, проверка — открыл URL с телефона.
- **Текст/UI, ноль графических ассетов** (кроме процедурных частиц).
- **Пошагово, не реалтайм** (одновременные ходы снимают и латентность LLM ~2 сек).
- **Атомарные итерации**: один промпт = одна проверяемая фича.
- Стек: React + TypeScript + Supabase + Anthropic API (совпадает с Null Club / CoachFlow — переиспользование паттернов).

## Известные риски (recap критики)

1. ~~Непредсказуемость собственных действий~~ → закрыто Прекастом.
2. ~~Схлопывание меты в 5 фраз~~ → закрыто Эрозией.
3. ~~Порог входа «сочинение»~~ → закрыто тремя уровнями ввода.
4. ~~Судья-чёрный-ящик~~ → закрыто Прекастом (трактовка видна до оплаты).
5. ~~Текстовый скриншот не мем~~ → закрыто реплей-гифками.
6. **Prompt injection против движка** → архитектурно смягчено (LLM не выдаёт числа), но требует ред-тиминга. ОТКРЫТО.
