# NEXORA — Концепт (актуальная версия)

> Статус: **ФАЗА 1 (мета-слой) ЗАКРЫТА (аудит v2)** — 18 итераций, D-001…D-049, два сквозных аудита. Следующая фаза: боевое ядро (Q-14…Q-17).
> Этот файл — единственный источник правды по концепту. Обновляется после каждой итерации обсуждения.

## Одной строкой

PvP-дуэль магов, где вместо кнопок скиллов — строка ввода: игрок пишет заклинание словами, LLM переводит фразу в строгую игровую структуру, детерминированный движок честно её исполняет.

## Почему это не сможет повторить большая студия

- Баланс невозможно гарантировать → нет киберспорта, нет обещания честности.
- Свободный текстовый ввод → модерация, сертификация сторов, юридический риск.
- Плавающая себестоимость матча (инференс) вместо нулевой.
- Матчи невоспроизводимы → нечего показать в трейлере как «геймплей».

Это структурная стена для корпораций и среда обитания для соло-разработчика.

## Кор-луп (один ход)

1. Экран дуэли: маг слева, маг справа. У игрока N Голоса и поле ввода (лимит 12 слов).
2. Игрок пишет фразу («Песок под его ногами превращается в стекло»).
3. **Прекаст**: перед отправкой игрок видит ПОЛНЫЙ разбор (единственный парс, D-058) — структура, точная цена. Можно переформулировать. Отправка = коммит хэша увиденной структуры: исполняется байт-в-байт она (D-004 физически ненарушим).
4. Ходы одновременные, вскрываются вместе (покерная модель).
5. LLM → строгая структура БЕЗ ЧИСЕЛ: {глагол, субстрат, аспекты, цель, величина-класс, длительность-класс, райдер} (D-051/D-059, спека в COMBAT-CORE.md). Числа и цену считает код.
6. Детерминированный слой валидирует и резолвит: применимость к среде, ресурсы, резисты, взаимодействие двух заклинаний.
7. Результат хода + автогенерируемая векторная анимация резолва.

**Ключевой принцип**: LLM никогда не решает исход и не выдаёт числа напрямую — только структуру, которую пересчитывает код. Хаос на входе, честность на выходе.

## Скилл игрока

Не реакция, не APM. Поиск формулировок с максимальным эффектом при минимальной цене + чтение противника. Эксплойты языка — не баг, а содержание игры.

## Гримуар (социальное ядро)

- Каждая фраза, впервые эффективно применённая в matchmade-дуэли (после Открытия Гримуара), записывается в летопись навсегда с именем автора.
- Первооткрыватель получает статус, роялти Дыханием (затухающие с эрозией, D-044) и право Сигнатуры (D-016) — перГолосентной скидки НЕТ, она отменена аудитом итерации 4.
- Известная фраза → закэшированный эффект → нулевая стоимость инференса. Платим LLM только за настоящую новизну (нормализация через мультиязычные эмбеддинги, не строковый матчинг).

## Эрозия заклинаний (анти-мета)

Чем чаще фраза используется, тем дороже она стоит. **Ключи эрозии = ключам открытий: кластер × среда** (D-043) — заезженность в Пустыне не дорожит фразу в Леднике. Лор: заезженные слова теряют силу, магия питается новизной. Механика: сходимость к мете автоматически делает мету дорогой → игра структурно заставляет творить. Кривая эрозии — предмет тюнинга.

## Три уровня ввода (порог входа)

| Уровень | Ввод | Аудитория |
|---|---|---|
| Казуал | Свайп по тегам-осколкам (стихия + действие + цель), движок собирает фразу | Массовый игрок |
| Мидкор | Пишет сам, лимит 12 слов | Ядро |
| Хардкор | Пишет сам + модификаторы стиля (бонус ТОЛЬКО за механически проверяемую форму: слоги/структуру считает код, не LLM-вкус — D-045) | Стримеры, контент |

Все три уровня попадают в один движок — баланс общий.

## Язык

**Ввод фраз — на любом языке** (LLM понимает всё). **Летопись едина по смыслу**: мультиязычные эмбеддинги кластеризуют «песок в стекло» и «sand to glass» в одно открытие — *смысл открывается один раз, на каком бы языке ни был произнесён* (D-048). Кросс-языковая точность кластеризации — гипотеза, проверяется в Безмолвии (→ Q-05). UI: EN первым (международный продукт), RU вторым.

## Виральность

- Реплей хода = автогенерируемая гифка: минималистичный вектор, две фигуры, эффекты частиц по типам из структуры, поверх — текст заклинаний. Шеринг одной кнопкой.
- Формат мема: «он написал ЭТО → произошло ВОТ ЧТО».
- Гримуар как лента открытий: охота за пустыми областями смыслового пространства.
- Публичная война разработчика с игроками, ломающими движок языком, — контент для канала Самурай AI.

## Технические рамки (продиктованы workflow)

Разработка: Cursor, промптами с телефона, свободное время. Отсюда жёстко:

- **Web-only**: деплой Vercel, проверка — открыл URL с телефона.
- **Текст/UI, ноль графических ассетов** (кроме процедурных частиц).
- **Пошагово, не реалтайм** (одновременные ходы снимают и латентность LLM ~2 сек).
- **Атомарные итерации**: один промпт = одна проверяемая фича.
- Стек: React + TypeScript + Supabase + Anthropic API (совпадает с Null Club / CoachFlow — переиспользование паттернов).

## Экономика и монетизация

**Стержневой принцип: деньги покупают пространство для творчества, не силу.**

- **Голос** — только внутри боя, не покупается никогда.
- **Дыханияа** — мета-ресурс, тратится на произнесение *нового* заклинания (нет в Гримуаре). Известные заклинания бесплатны (кэш). Дыханияа = зеркало себестоимости инференса: игровой ресурс совпадает с юнит-экономикой.

| Режим | Голос | Новые заклинания | Дыханияа |
|---|---|---|---|
| Рейтинг | в бою | 3/дуэль, бесплатно, у всех | не действуют |
| Казуал | в бою | из дневного запаса | тратятся |
| Эхо (песочница) (песочница, Голосекен) | ∞ | сколько есть Дыхания | основная топка |

**Анти-P2W**: в рейтинге бюджет новизны уравнен для всех, Дыханияа не работают. Платящий получает из Эха только знание (проверенные формулировки) — легитимное преимущество уровня «купить шахматный учебник».

**Роялти Дыханием**: твоё заклинание используют другие → капают Дыханияа, **эмиссия затухает с эрозией фразы** (D-044) — станка бесконечных Дыхания не существует. Талантливый творец играет бесплатно — осознанная витрина модели.

**Защита кошелька разработчика**: дневной лимит Дыхания = потолок расходов на игрока; ступень-1 микроклассификатор мусора/safety перед единственным парсом (D-058); кэш кластеров с первого дня (D-033).

**Открытие только кровью**: заклинание регистрируется в Гримуаре при первом эффективном применении в матче против человека, не в Эха. + Кластеризация эмбеддингов против сквоттинга вариаций.

**Источники дохода**: подписка «Кодекс» ~$6/мес (Дыханияа для Эха, косметика, страница автора) + разовая косметика (анимации резолва, сигилы, оформление Гримуара, титулы) + сезонные тома.

## Прогрессия и чувство роста

**Рост в ширину, не в высоту**: ветеран не бьёт больнее — у него больше выразительных средств.

**Сигнатуры** (замена роялти-скидки из ранней версии D-005, см. D-016):
- Автор «подписывает» своё открытие → для него оно навсегда стоит базовую цену, иммунитет к эрозии. Лор: слово слушается того, кто произнёс его первым.
- Слотов печатей мало: 3 на старте → 7–9 максимум. Растут только игрой (уровень мага), не деньгами.
- Набор сигнатур = билд-идентичность мага. Тебя читают и узнают по печатям.
- Расширение слотов = ощутимая прогрессия без роста цифр урона.

## Ценность аккаунта

Аккаунт = библиотека и репутация: летопись открытий (вечна), активные сигнатуры, роялти-поток, титулы, архив реплеев, рейтинг.

**Решение проблемы позднего игрока** (пространство открытий исчерпаемо):
1. **Контекстные открытия**: открытие = заклинание × среда. Новая арена каждый сезон = новая целина. Среды обязательны (закрывает направление Q-02).
2. **Выцветание**: заклинание без использования целый сезон теряет активную печать и может быть переоткрыто. Летопись первого автора вечна; власть циклична. Два слоя UI: «Открыто [имя], сезон N» (навсегда) + текущий держатель печати.
3. **Локальные первенства**: первый в лиге / сезоне / арене — новичок конкурирует в своём слое.

## Удержание

- **Ядро — асинхронные дуэли** («шахматы по переписке»): 3–5 живых дуэлей одновременно, ход противника = органическая нотификация. Одновременные ходы (D-003) делают асинхрон технически тривиальным и решают матчмейкинг малой базы на старте. Синхронная дуэль = тот же движок в быстром темпе (Q-03 закрыт).
- Дневной якорь: запас Дыхания + дневной контракт (v1.1).
- Недельный: турнир (v1.2). Сезонный: новый том + новая арена.
- Анти-пуш-усталость: агрегация нотификаций, тихие часы по умолчанию.
- **MVP retention = только асинхрон + дневные Дыханияа.** Остальное после живой базы (анти-scope-creep).

## Эволюция механики без патчей

- Эрозия непрерывно двигает мету сама — игра эволюционирует без патч-нотов.
- Сезонная арена = новое пространство открытий (твик тегов среды, не контент-производство).
- Мировые события («Затмение: ментальная магия −20% на неделю») = твик одного коэффициента детерминированного слоя = иллюзия контент-конвейера большой студии.

## Запуск: Эпоха Безмолвия

- До старта первого сезона игра полностью играбельна, но **Гримуар запечатан** — открытия не регистрируются. Игроки копят находки в личных записях.
- **Первое Слово (бывш. Открытие Гримуара)** — событие запуска (земельная гонка): назначенная дата, летопись распечатывается, подготовленные бегут столбить.
- Бонусы Безмолвия: окно ред-тиминга парсера без вечных последствий (Q-04); калибровка кривой эрозии на живых данных (Q-05); честность к поздним игрокам (летопись рождается чистой).
- Дата Открытия назначается по метрике живой базы, не по календарю. Контент-кампания канала Самурай AI строится вокруг дедлайна.
- Открытия регистрируются **только в matchmade-дуэлях** (казуал/рейтинг). Дуэли с другом играбельны, но не регистрируют (анти-сговор) — UI обязан это явно показывать. ИИ-матчи не регистрируют никогда.
- **Рейтинг открывается не раньше Открытия Гримуара** (D-047): в Безмолвии кэш холодный, бюджет «3 новых/дуэль» душил бы игру. Безмолвие живёт казуалом и Эхом.
- **Цена фиксируется в момент отправки хода** (D-046): эрозия между отправкой и асинхронным резолвом не меняет уплаченного. Прекаст-контракт нерушим.

## Психология игрока

**Проигрыш.** В игре про творчество поражение = «моя идея хуже» — удар по идентичности, риск retention №1. Механизмы:
1. **Судья нем в вопросах качества**: язык прекаста/резолва — только физика («камень, зона, 2 хода, 6 Голоса»). Голос = масштаб, не достоинство. Система никогда не хвалит и не ругает; похвала — только от людей (восхищения в Гримуаре, реакции).
2. **Экран поражения начинается с добычи**: увиденные заклинания противника с разбором → записная книжка. Проигрыш = разведка.
3. **Культ КПД**: подсвечиваемая метрика — эффект/Голос. Элегантность — официальная ось мастерства; «он экономнее» лечится обучением, «он талантливее» — нет.
4. **Асинхрон-амортизатор**: поражение узнаётся в спокойный момент среди ходов других дуэлей. Реванш одной кнопкой.
5. **Никаких скрытых поддавков**: честный судья распространяется на матчмейкинг.

**Петля дистрибуции**: проигравший получает разбор → может кастовать заклинание победителя → роялти автору (D-013). Каждое поражение — дистрибуция бренда победителя; победа двумерна (рейтинг + посев своих слов).

**Чистый лист.** Ступор перед пустым вводом страшнее проигрыша. Решение — **арена как муза**: свойства среды выложены на экран словами-аффордансами (Пустыня: песок, жара, миражи, открытое небо). Не подсказки-фразы (убили бы авторство), а сырьё для идей + честная декларация физики арены.

## Онбординг: первые десять минут

Целевая метрика: **time-to-magic < 60 сек** («я написал СВОИ слова — и мир подчинился»). Web: открыл URL — уже внутри. Без регистрации, меню, синематиков.

- **0:00** Холодный старт в сцену: зала, три аффорданса (*камень, тьма, эхо*), голос Гримуара: «Скажи слово — и мир услышит». Гостевой аккаунт молча.
- **0:20** Первое слово. **Мир всегда отвечает**: «invalid input» не существует, любой ввод резолвится минимум в шёпот (0 эффекта, 0 Голоса, бесплатно). Оба входа видны сразу: свободное поле (курсор в нём) + «собрать из осколков» (тир выбирается самоопределением; порядок — A/B в прототипе).
- **1:00** Инициация: дух-наставник **объявляет себя учителем** («Я не сражаюсь — я проверяю, слышит ли тебя мир»). Обучение подражанием: простые читаемые фразы духа, показ связи с аффордансами среды делом. Ключевая реплика про прекаст: «Переписывай черновик сколько хочешь — слово в черновике ничего не стоит».
- **~4:00** Конец Инициации = первое эффективное заклинание игрока. Не победа — «мир тебя услышал». Поражения в Инициации нет. Честность буквальна: наставник открыт, поддавков нет (согласовано с D-028).
- **5:00** Экран добычи (записная книжка — D-026 на позитиве) → страница мага → «Как мир запомнит тебя?» — имя после инвестиции.
- **6:00–10:00** Первая matchmade async дуэль в очереди; пока ждёшь — Эхо (песочница) и второй дух (честный ИИ, спарринг помечен как нерегистрирующий). Видимый таймер дневных Дыхания. Выход с открытой петлёй (эффект Зейгарник).
- Мёртвая пауза: матчмейкинг приоритетно сводит новичков; при отсутствии человека X часов дух предлагает спарринг.

## Воронка виральности

Каждая шаренная реплей-страница заканчивается полем ввода: «Скажи своё слово». Гифка → реплей → первое слово → Инициация → дуэль, без границы между «посмотреть» и «играть». Web-платформа = стратегическое преимущество: между мемом и игрой один тап, а не стор. Требует rate-limit Инициации по IP (→ Q-04).

## Слои кэша и летописи (уточнение Эпохи Безмолвия)

**Инфраструктурный кэш** (кластеризация эмбеддингов + кэш резолвов) работает с первого дня и не зависит от Безмолвия — иначе предсезон был бы периодом максимальной себестоимости при нуле роялти. **Летопись** (имена, печати, роялти) открывается только событием Открытия Гримуара. Кэш греется весь предсезон → к Открытию себестоимость хода минимальна.

## Социальный слой

Планка отсечения: фича входит, только если усиливает фантазию «слова = власть», дешева и не рождает модерационный кошмар. Половина социальности уже встроена: имена летописи, роялти, петля поражений, реплей-воронка.

- **Восхищения**: одно в день на мага (дефицит = вес похвалы + дневной ритуал). Старт — на Открытии Гримуара.
- **Театр реплеев** (v1.1): автокурируемая лента лучших резолвов (КПД / новизна / восхищения). Внутренний TikTok без редактора.
- **Родословная** (v1.1): пришедший по реплей-ссылке записывает автора как «первое слово»; у ветерана растёт древо магических линий. Чисто косметическая слава, ноль экономических наград (анти-MLM).
- **Школы-знамёна** (v2): тег + общая полка сигнатур + сезонная лига школ. **Без внутреннего чата** — чат отдан внешним инструментам навсегда.
- Спектейт-ссылка живой синхронной дуэли (v1.2, для стримеров).
- **Отклонено навсегда**: дуэли со ставками, кооперативный каст, встроенный чат.

## Модерация: «мир отвергает скверну»

Игра публикует пользовательский текст (летопись, ленты, реплеи) — слой безопасности обязателен до любого запуска.

1. Safety-класс едет верхом на том же LLM-вызове парсинга — нулевая маржинальная стоимость.
2. Модерация в лоре: токсичную фразу *отказывается произносить мир* («эти слова не находят отклика»). Отказ — легитимный тип ответа, совместим с «мир всегда отвечает».
3. Прекаст = превью модерации: отказ виден в черновике, бесплатно и приватно; цена ложного срабатывания — ноль. Эскалация только за упорные повторы.
4. Ворота публикации: приватный резолв и попадание в летопись/ленту/шаринг — разные пороги строгости.
5. Защита бюджета: ступень-1 микроклассификатор (мусор/safety) → единственный парс только валидного (D-058) + IP-лимиты.

## Итоги аудита Фазы 1

Разрешённые напряжения: КПД = арифметика, не похвала (граница D-025/D-027); тупик Инициации закрыт подводом к осколкам после N шёпотов; новизна для Дыхания = промах кэша (не летопись); отказ мира = тип ответа. Оси заказчика: вовлечённость / эволюция механики / удержание / чувство роста / ценность аккаунта — каждая закрыта ≥2 механиками, ни одна не продаётся за деньги. Найдено и заделано за фазу 6 дыр: D-005×D-012, поздний игрок, холодный старт, экономика Безмолвия, модерация, тупик Инициации.
