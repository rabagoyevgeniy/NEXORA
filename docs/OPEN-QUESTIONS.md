## Q-08. Числа (консолидированный чек-лист Безмолвия)

- Экономика: цена подписки; дневной запас Чернил; кривая роялти + дневной кап (D-081); бюджет новизны в рейтинге (3/дуэль).
- Бой: таблица база[глагол][величина]; налоги длительности/райдера; кривые эрозии и утомления (+1 класс — гипотеза); мана 6/+3/кап12; Стойкость 20; длина 6–10 ходов.
- Контракт: лимит промахов кэша/ход; TTL цены черновика (~10 мин); порог τ кластеризации (+ кросс-языковой).
- Сезоны: том закрывается? эрозия сбрасывается? длительность Безмолвия и метрика готовности.
- Красные флаги баланса: сковать/слово; стилевая скидка; сговор-паттерны роялти.
- После запуска: «Кинематограф» (цена рендера, лимиты тиров, пайплайн Seedance/Higgsfield, водяной знак).
- Решать только на данных, не теоретизировать.

## ~~Q-12. Социальный слой~~ [ЗАКРЫТ → D-036…D-041]

## Q-13. FTUE-метрики и A/B (прототип)

- Time-to-magic факт vs цель 60 сек; конверсия Инициация → первая async дуэль; retention D1 гостей с реплей-воронки.
- A/B: первый ввод свободный vs осколки (гипотеза: свободный выигрывает retention, осколки — конверсию первой минуты).

## Q-19. Юридика (исполнение, не дизайн)

- ToS: лицензия на пользовательские фразы (вечная публичная летопись!), приватность, возрастной порог.
- Платежи: web = Stripe напрямую, без 30% сторов (зафиксировать как преимущество в питчах).
- Поп-культурные фразы в летописи (франшизные «заклинания»): оценка риска торговых марок в UGC.

## Q-20. UX-бэклог (не блокеры)

- Vacation-режим асинхрона (пауза 48ч-таймеров по обоюдному согласию).
- Лимит слов у казуала = меньше осколков в сборке (интерфейсное следствие сковать/разум).
- Духи: ходят преимущественно известными кластерами (бесплатно), LLM-генерация фраз в персоне — редко (стоимость) → детали в Фазе контента.
